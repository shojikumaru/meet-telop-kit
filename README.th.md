<a id="problems"></a>

## เคยเจอปัญหาแบบนี้ไหม?

- **วิดีโอบันทึกกองพะเนิน** — บทสัมภาษณ์ดี ๆ ถูกเก็บไว้ใน Google Drive โดยไม่เคยได้ใช้
- **โปรแกรมตัดต่อใช้ยาก** — การตัด ใส่ซับไตเติล และเอฟเฟกต์ ต้องใช้ทักษะที่คุณไม่มี
- **เทโลปกินเวลาหลายชั่วโมง** — พิมพ์ซับไตเติลและป้ายชื่อเองทีละอันจนหมดวัน
- **จ้างคนอื่นก็แพง** — จ้างคนตัดต่อทุกครั้งที่สัมภาษณ์ ค่าใช้จ่ายสูงขึ้นเรื่อย ๆ

<a id="what-it-does"></a>

## ทำอะไรได้

ให้ลิงก์แชร์ของ Google Drive และชื่อของผู้พูด แล้ว Claude Code on the web (Claude ที่ทำงานบนคลาวด์) จะตัดต่อบนคอมพิวเตอร์คลาวด์ และนำวิดีโอที่เสร็จแล้วไปไว้ในสำเนาส่วนตัวของชุดเครื่องมือนี้ของคุณ

```mermaid
flowchart LR
    A["ลิงก์ Google Drive<br/>+ ชื่อผู้พูด"] --> B["Claude บนคลาวด์<br/>(claude.ai/code)"]
    B --> C["วิดีโอพร้อมเทโลป<br/>ในสำเนาส่วนตัวของคุณ"]
```

- 🎬 **วิดีโอโฆษณายาวประมาณ 5 นาที**

  Claude เลือกช่วงเปิดที่น่าสนใจและช่วงถาม-ตอบจากบทสัมภาษณ์ แล้วตัดให้เหลือประมาณ 5 นาที

- 💬 **เทโลปสไตล์ YouTube**

  ซับไตเติลของผู้พูด ป้ายชื่อ หัวข้อคำถาม ตัวเลขเด้ง เสียงประกอบ และการ์ดปิดท้าย

- 🖼️ **ตรวจก่อนส่งออก**

  Claude จะให้ดูภาพนิ่งก่อน คุณขอแก้ไขได้ด้วยภาษาธรรมดา

- 📦 **ส่งไปยังสำเนาส่วนตัวของคุณ**

  ไฟล์ mp4 ที่เสร็จแล้วจะอยู่ใน GitHub repository ของคุณเอง พร้อมดาวน์โหลด

เทโลป คู่มือทีละขั้นตอน และคำตอบของ Claude เป็นภาษาญี่ปุ่น

<a id="requirements"></a>

## สิ่งที่ต้องมี

ทุกอย่างทำงานในเบราว์เซอร์ที่ claude.ai/code ประสิทธิภาพของคอมพิวเตอร์คุณไม่มีผล

- **บัญชี Claude** — แพ็กเกจ Pro, Max, Team หรือ Enterprise
- **บัญชี GitHub** — ฟรี วิดีโอจะถูกส่งไปยัง repository ส่วนตัวที่นั่น
- **วิดีโอบันทึกบน Google Drive** — และความยินยอมของทุกคนในวิดีโอ

| รายการ | สถานะ | หมายเหตุ |
| :- | :- | :- |
| Claude Code on the web ในเบราว์เซอร์บนคอมพิวเตอร์ | ✅ | |
| แอป Claude Desktop (Cloud) | ⚠️ | ยังไม่ได้ทดสอบ |
| แอป Claude บน iPhone (แท็บ Code) | ⚠️ | ชุดนี้ยังไม่ได้ทดสอบบน iPhone คู่มือนี้เขียนและทดสอบสำหรับเบราว์เซอร์บนคอมพิวเตอร์ จึงควรตั้งค่าบนคอมพิวเตอร์ |
| คอมพิวเตอร์คลาวด์: Ubuntu 24.04 | ✅ | สภาพแวดล้อมที่ Claude Code on the web จัดให้ |
| รันทดสอบบน macOS (`make test`) | ✅ | |
| แพ็กเกจ Claude | จำเป็น | Pro / Max / Team / Enterprise ตามเอกสารของ Anthropic (2026-10-05) |
| ดาวน์โหลดวิดีโอบันทึก: ลิงก์แชร์ Google Drive (วิดีโอบันทึกจาก Meet) บน macOS | ✅ | วัดจริงด้วย `scripts/fetch_drive.sh` (2026-10-05) |
| ดาวน์โหลดวิดีโอบันทึก: ลิงก์แชร์ Google Drive บนคอมพิวเตอร์คลาวด์ | ⚠️ | 動作テスト ตรวจเพียงว่าเชื่อมต่อเซิร์ฟเวอร์ของ Drive ได้ ส่วนลิงก์แชร์ของคุณจะถูกตรวจตอนเริ่มงานจริง |
| แหล่งวิดีโอ: วิดีโอ Zoom ที่นำไปไว้บน Google Drive | ⚠️ | ยังไม่ได้ทดสอบ |

Team / Enterprise: ผู้ดูแล (Owner) ต้องอนุญาต Claude Code on the web และการเชื่อมต่อกับ GitHub

<a id="get-started"></a>

## เริ่มต้นใช้งาน

ทำ 3 ขั้นตอนครั้งเดียว แต่ละขั้นตอนมีลิงก์ที่กดได้ทันที

| | สิ่งที่ต้องทำ | เปิด |
| :- | :- | :- |
| ① | **สร้างสำเนาของคุณเอง** (การมองเห็นต้องเป็น **Private**) | <https://github.com/shojikumaru/meet-telop-kit/generate> |
| ② | **เชื่อมต่อ Claude และสร้าง environment ชื่อ `video`** | <https://claude.ai/code> |
| ③ | **ส่ง「動作テスト」** (การตรวจการตั้งค่า) | <https://claude.ai/code?prompt=%E5%8B%95%E4%BD%9C%E3%83%86%E3%82%B9%E3%83%88&environment=video> |

- **เวลาที่ใช้ (ประมาณการ)** — บนคอมพิวเตอร์ 20–30 นาที ถ้าสร้างบัญชีใหม่เพิ่มอีก 10–15 นาที
- **動作テスト** — ประมาณ 3–6 นาที (ประมาณการ) ตรวจว่าคอมพิวเตอร์คลาวด์เชื่อมต่อเซิร์ฟเวอร์ของ Google Drive และ Hugging Face (ที่เก็บโมเดลถอดเสียง) ได้ ถ้าวิดีโอทดสอบ 10 วินาทีมาถึงสำเนาของคุณ แปลว่าพร้อมแล้ว

การทำวิดีโอจากวิดีโอบันทึก: แชร์วิดีโอบน Google Drive เป็น "ทุกคนที่มีลิงก์" เปิด claude.ai/code เลือกสำเนาของคุณและ environment `video` แล้วส่งข้อความคำขอจากคู่มือโดยใส่ชื่อผู้พูด Claude จะตรวจลิงก์ ให้ดูภาพนิ่งเพื่อขอความเห็นชอบ แล้วจึงส่งวิดีโอ (ประมาณ 30 นาทีถึง 1 ชั่วโมงต่อวิดีโอ เป็นค่าประมาณการ)

คู่มือฉบับเต็ม (ต้องกดตรงไหน และข้อความสำหรับคัดลอก) อยู่ที่ [docs/はじめに.md](docs/はじめに.md) (ภาษาญี่ปุ่น)

<details>
<summary>เมื่อเกิดปัญหา</summary>

- **「ネットワークにつながりません」(เชื่อมต่อเครือข่ายไม่ได้)** — เซสชันไม่ได้ใช้ environment `video` หรือโดเมนที่อนุญาตไม่ถูกต้อง
- **「共有されていません」(ไม่ได้แชร์)** — ตั้งการแชร์ของวิดีโอบน Drive เป็น "ทุกคนที่มีลิงก์"
- **ได้แค่แผนงานกลับมา** — เปลี่ยนโหมดจาก "Plan" เป็น "Auto" หรือ "Accept edits" แล้วส่งใหม่
- **ไม่เห็นสำเนาของคุณในรายการ** — ติดตั้ง Claude GitHub App ให้กับสำเนาของคุณ

รายการทั้งหมดอยู่ในหัวข้อที่ 7 ของ [docs/はじめに.md](docs/はじめに.md)

</details>

<a id="safety"></a>

## ทำไมจึงใช้ได้อย่างสบายใจ

ชุดเครื่องมือนี้ออกแบบให้วิดีโอและชื่ออยู่เฉพาะที่ที่คุณวางไว้

- **สำเนาของคุณเป็นแบบส่วนตัว** — วิดีโอถูกส่งไปยังสำเนาส่วนตัวของคุณเท่านั้น ไม่ส่งไปที่อื่น
- **ไม่แต่งชื่อขึ้นเอง** — ถ้าขาดชื่อหรือตำแหน่ง Claude จะถามคุณ
- **แชร์ลิงก์ Drive เฉพาะตอนทำงาน** — เมื่อวิดีโอมาถึงแล้ว ให้ตั้งกลับเป็น "จำกัด"
- **จำกัดการเชื่อมต่อ** — คอมพิวเตอร์คลาวด์เข้าถึงได้เฉพาะ 6 โดเมนที่กำหนดและแหล่งแพ็กเกจ
- **การขอความยินยอมเป็นหน้าที่ของคุณ** — ขออนุญาตทุกคนในวิดีโอก่อนทำวิดีโอ
