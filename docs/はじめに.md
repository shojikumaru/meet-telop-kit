# はじめに — 対談の録画からテロップ入り動画を作る

Google Meet や Zoom で録画した対談から、YouTube 風のテロップ入り「約5分の広告版」を作る手順です。
実際の作業はオンラインの Claude（claude.ai/code）がクラウドのパソコンで行います。

- パソコンの性能は関係ありません。この手順はパソコンのブラウザ向けに書いて、パソコンのブラウザで確かめたものです
- このキットは iPhone では確かめていません。設定はパソコンで行ってください
- 最初の設定は1回だけ。2回目からは文章を1つ送るだけです
- できた動画は、**あなた自身の GitHub リポジトリ**（自分専用の保管場所）に届きます

> 画面の一部は英語です。この手順では、ボタンの名前を **英語（日本語）** の両方で書いています。

---

## 3ステップ（まずはここだけ）

| | やること | 開くリンク |
| :- | :- | :- |
| ① | **自分用のコピーを作る**（公開範囲は必ず **Private**） | <https://github.com/shojikumaru/meet-telop-kit/generate> （パソコンのブラウザで開く） |
| ② | **Claude とつなぐ・環境 `video` を作る** | <https://claude.ai/code> |
| ③ | **「動作テスト」と送る** | <https://claude.ai/code?prompt=%E5%8B%95%E4%BD%9C%E3%83%86%E3%82%B9%E3%83%88&environment=video> |

- ③のリンクで入力欄に「動作テスト」が入らないときは、自分で「動作テスト」と入力し、リポジトリ（①のコピー）と環境（`video`）を選んでから送ってください
- かかる時間の目安（見積もり）: パソコンで 20〜30分 / アカウントを新しく作るなら さらに 10〜15分。動作テストそのものは 3〜6分が目安です
- くわしい手順は下の「2.」「3.」にあります

目次:

1. 用意するもの
2. 最初の1回だけやること
3. 動作テスト（録画なしで試す）
4. 新しい録画で動画を作る
5. できた動画の受け取り方
6. 録画の共有と、写っている人への配慮
7. うまくいかないとき

---

## 1. 用意するもの

| もの | 説明 |
| :- | :- |
| Claude のアカウント | **Pro / Max / Team / Enterprise** のどれか。Claude のアプリかブラウザでログインしておきます。Team / Enterprise では、管理者（Owner）が Claude Code on the web（クラウドで動かす機能）と GitHub との連携を許可している必要があります |
| GitHub のアカウント | 無料。<https://github.com/signup> で作れます |
| 録画ファイル | Google Drive に置いたもの（Meet の録画は自動で Drive に入ります） |
| 写っている人の了解 | 録画に写っている人・話している人全員に、動画にしてよいか先に聞いておきます（「6.」参照） |

---

## 2. 最初の1回だけやること

### 2-1. 自分用のコピーを作る

このキットは「ひな形（テンプレート）」です。そのまま使わず、**自分専用のコピー** を作ってそちらを使います。

1. <https://github.com/shojikumaru/meet-telop-kit/generate> を **パソコンのブラウザ** で開く
   - GitHub にログインしていなければログインします。確認コード（メールなどに届く数字）を聞かれたら入力します
   - 画面が出ないときは <https://github.com/shojikumaru/meet-telop-kit> を開いて、緑のボタン
     **「Use this template」**（このテンプレートを使用）→ **「Create a new repository」**（新しいリポジトリを作成）を押す
2. 次のように入力する

| 項目 | 入れる内容 |
| :- | :- |
| Owner（所有者） | 自分のアカウント |
| Repository name（リポジトリ名） | 好きな名前（例: `my-telop-videos`） |
| 公開範囲 | **Private**（プライベート）を選ぶ ← とても大事 |
| Include all branches（すべてのブランチを含める） | チェックしない |

3. **「Create repository」**（リポジトリを作成）を押す

> 必ず **Private** にしてください。Public（公開）にすると、届いた動画を誰でも見られてしまいます。

### 2-2. Claude と GitHub をつなぐ

Claude があなたのコピーを読み書き（動画を届ける）できるようにする設定です。

1. <https://claude.ai/code> を開き、Claude のアカウントでログインする
2. **「Sign in with GitHub」**（GitHub でサインイン）を押す → GitHub の許可の画面で、許可するボタンを押す
3. 続けて、Claude の GitHub アプリを入れる
   （案内が出ないときは <https://github.com/apps/claude/installations/new> を開く）
   - 自分のアカウントを選ぶ
   - **「Only select repositories」**（選択したリポジトリのみ）を選び、
     「Select repositories」（リポジトリを選択）で **2-1 で作ったコピーだけ** を選ぶ
   - **「Install」**（インストール）を押す
4. このあと
   - **Pro / Max** の人: 「Default」という名前の環境が自動でできます。次の 2-3 で、動画づくり用の環境 `video` を追加します
   - **Team / Enterprise** の人: 「Create your first cloud environment」（最初のクラウド環境を作る）という入力画面が出ます。
     2-3 の表のとおりに入力して、名前を `video` にしてください

### 2-3. 環境を作る（クラウドの環境 `video`）

「環境」は、クラウドのパソコンの設定です。そのパソコンがインターネットのどのサイトにつないでよいかと、
最初に何を入れておくかを決めます。最初の状態では Google Drive につながらないので、動画づくり用の環境を1つ作ります。

> この 2-3 は **パソコンのブラウザ（claude.ai/code）** で行ってください。この手順はパソコンのブラウザ向けに書いて確かめたもので、
> このキットは iPhone では確かめていません。

1. <https://claude.ai/code> を開く
2. 入力欄のすぐ上の行にある **「☁ Default」（いまの環境の名前が書いてあるボタン）** を押す
   （日本語の画面では「＋ リポジトリを選択…」の左にあります）
3. **「Cloud」**（クラウド）→ **「Add cloud environment」**（クラウド環境を追加）を押す
4. 次のように入力する

| 項目 | 入れる内容 |
| :- | :- |
| Name（名前） | `video` |
| Network access（ネットワークの接続） | **Custom**（カスタム）を選ぶ |
| Allowed domains（許可するドメイン） | 下の6行をそのまま貼る |
| 「Also include default list of common package managers」（よく使うパッケージ取得先も含める） | **チェックを入れる**（動画ソフトのインストールに必要） |
| Environment variables（環境変数） | 空のまま |
| Setup script（セットアップスクリプト） | 下のスクリプトを貼る（任意。貼ると2回目以降の準備が速くなります） |

5. **「Create environment」**（環境を作成）を押す

許可するドメイン（6行。1行ずつ、このままコピーして貼ってください）:

```
drive.google.com
drive.usercontent.google.com
*.googleusercontent.com
huggingface.co
*.huggingface.co
*.hf.co
```

- 上の3行 = Google Drive から録画をダウンロードするため
- 下の3行 = 文字起こしのモデル（574MB）をダウンロードするため

セットアップスクリプト（任意）:

```bash
#!/bin/bash
apt-get update -qq
DEBIAN_FRONTEND=noninteractive apt-get install -y -qq --no-install-recommends ffmpeg fonts-noto-cjk fonts-noto-cjk-extra python3-venv python3-pip curl ca-certificates
python3 -m venv "$HOME/.cache/meet-telop/venv"
"$HOME/.cache/meet-telop/venv"/bin/pip install -q --disable-pip-version-check --only-binary :all: pillow pywhispercpp==1.5.1
```

これはリポジトリの `scripts/setup.sh` と同じ中身です（パッケージや保存場所を変えるときは両方そろえてください）。
貼らなくても、Claude が作業の最初に `bash scripts/setup.sh` で同じ準備を自動で行います（初回 2〜3 分）。

### 送る前に: モードは「Auto」か「Accept edits」

入力欄の近くにあるモードの切り替えが **「Plan」**（計画）になっていると、Claude は計画を立てるだけで、
動画は作りません。**「Auto」**（自動）か **「Accept edits」**（編集を許可）にしてから送ってください
（「Auto」は選べる場合だけ表示されます）。

## 3. 動作テスト（録画なしで試す）

設定がうまくいったかを、録画を使わずに確かめます。10秒くらいのテスト動画（カラーバーにテロップが出るもの）が
あなたのコピーに届けば成功です。

1. <https://claude.ai/code?prompt=%E5%8B%95%E4%BD%9C%E3%83%86%E3%82%B9%E3%83%88&environment=video> を開く
   （入力欄に「動作テスト」が入り、環境が `video` になります。入らないときは、自分で「動作テスト」と入力します）
2. **リポジトリ = 2-1 で作ったコピー**、**環境 = `video`** になっているか確かめる
3. 「動作テスト」の一言を送る
4. 3〜6分（目安）で、次の3つが返ってきます
   - ① 合否（合格 / 不合格）
   - ② 動画のリンク（合格のとき。見方は「5. できた動画の受け取り方」）
   - ③ 次にやること（不合格のときは、原因と直し方）

動作テストで確かめること:

- クラウドのパソコンから、このキットが使うサーバーにつながるか: Google Drive のサーバー（録画のダウンロードに使う
  drive.google.com・drive.usercontent.google.com と、googleusercontent.com のサーバー1つ）と、
  Hugging Face（文字起こしモデルの置き場）のサーバー
- 動画ソフトなどの準備（インストール）ができるか
- テスト動画を書き出せるか
- あなたのコピーに動画を届けられるか

確かめられないこと: **あなたの録画の共有リンクが開けるか** は、ここでは分かりません。
本番（「4.」）の最初に Claude が確かめて、開けなければその場で教えてくれます。

## 4. 新しい録画で動画を作る

1. 録画を Google Drive で「リンクを知っている全員」に共有して、リンクをコピーする（「6.」参照）
2. <https://claude.ai/code> で、**リポジトリ = 自分のコピー**、**環境 = `video`** を選ぶ
3. 下の文章の `<…>` の部分を書き換えて送る

```
この録画から約5分の広告版を作ってください。
録画: <Google Drive の共有リンク>
話している人（画面に出す名前と肩書き）:
- <名前>（<会社名・肩書き>）… ゲスト
- <名前>（<会社名・肩書き>）… 聞き手
使いたい部分: <例: 後半のインタビューのところ。わからなければ候補を出して聞いてください>
見せたいポイント: <例: 料金と導入事例の話を中心に>
最初の大見出し: <例: 〇〇を△△で解決した話。おまかせなら「おまかせ」>
エンドカードの文字: <例: 続きは本編で！。おまかせなら「おまかせ」>
書き出す前に、静止画を何枚か見せて確認を取ってください。
```

- Claude は最初に、録画のリンクが開けるかを確かめます。開けないときは理由（共有の設定・リンクの間違いなど）を教えてくれます
- **名前と肩書きは必ず書いてください。** 書いていないと Claude が質問してきます（勝手に名前を作ることはしません）
- 途中で Claude から質問が来たら、答えを返すと続きを進めます
- 静止画（途中の確認画像）を見て、直したいところがあればそのまま文章で伝えてください
  （例: 「2枚目の字幕の『〇〇』を『△△』に直して」）
- 1本あたりの目安: 30分〜1時間くらい（録画の長さと文字起こしの量によります）

## 5. できた動画の受け取り方

Claude が最後に返すリンクは、次のどちらかの形です。どちらも **あなたのコピーの中** にあります。

- `…/releases/…` のリンク: 開くとそのままダウンロードできます
- `https://github.com/<あなた>/<コピーの名前>/blob/deliver/○○/△△.mp4` のリンク（`deliver/○○` という名前の置き場所）:
  - **iPhone**: リンクを開く →（GitHub にログインした状態で）右上の「⋯」→ **「Download」**（ダウンロード）
    → ファイルアプリの「ダウンロード」に保存されます。写真アプリに入れたいときは、ファイルを開いて共有ボタン →「ビデオを保存」
  - **パソコン**: リンクを開く → 右上の **「Download raw file」**（下向き矢印のボタン）
  - この置き場所には 1本 95MB までしか置けません。大きいときは Claude が画質を少し落として（1080p のまま）から届けます

あとから探すときは、自分のコピーのページで、左上のブランチ名（「main」と書いてあるボタン）を押すと
`deliver/…` の一覧が出ます。いらなくなったものは「Branches」（ブランチ）ページのゴミ箱ボタンで消せます。

## 6. 録画の共有と、写っている人への配慮

### Google Drive の共有（作るときだけ公開して、終わったら戻す）

1. Google Drive で録画ファイルの「︙」→ **「共有」** →「共有」
2. 「一般的なアクセス」を **「リンクを知っている全員」**（閲覧者）にする
3. 「リンクをコピー」して、4. の文章に貼る
4. **動画が届いたら、同じ画面で「制限付き」に戻す**

「リンクを知っている全員」になっている間は、リンクを知っている人なら誰でも録画を見られます。
共有する時間はできるだけ短くしてください。

### 写っている人・声が入っている人への配慮

- 録画に写っている人・話している人 **全員に、動画にしてよいか先に了解をもらってください**
  （どこで使うか ― 社内だけ / SNS / 広告 ― も伝えておくと安心です）
- 画面共有の中に、メールアドレス・お客さまの名前・社内の数字などが映っていないか、
  Claude が見せる静止画と、届いた動画で確認してください。気になる場面は「その部分は使わないで」と伝えれば外せます
- コピーは必ず **Private** のままにしてください。コピーを見られる人を増やすときは、見せてよい人だけにしてください

## 7. うまくいかないとき

| こんなとき | どうする |
| :- | :- |
| 「ネットワークにつながりません」と言われた | 環境が `video` になっていないか、許可するドメインの6行が違います。2-3 を確認して、環境 `video` を選んだ新しい会話でもう一度送る |
| 「共有されていません」「案内ページが返ってきました」と言われた | Drive の共有が「リンクを知っている全員」になっていません（6. を確認）。なっているなら、ダウンロード回数の上限かもしれないので時間をおいて送る |
| 「録画が見つかりません」と言われた | 共有リンクが途中で切れていないか、ファイルが消えていないかを確認して、リンクを貼り直す |
| 「deliver FAILED」と言われた | 動画を届けられませんでした。Claude の GitHub アプリがコピーに入っているか（下の「リポジトリが出てこないとき」）を確認して、「もう一度届けて」と送る |
| Claude がリポジトリを選べない・見つからない | 下の「リポジトリが出てこないとき」を見る |
| 計画だけ返ってきて、何も作られない | モードが「Plan」になっています。「Auto」か「Accept edits」にして送り直す（2. の最後を参照） |
| 途中で止まった・返事が来ない | 同じ会話で「続きからお願いします」と送る（ダウンロードは途中から再開できます） |
| 名前や字幕が間違っている | 「〇〇の名前を△△に直して、もう一度書き出して」と送る |
| 動画が大きすぎて届かない | Claude が自動で小さくしてから届けます。元の画質が必要なら「Releases に届けて」と伝える |

### リポジトリが出てこないとき

リポジトリを選ぶ一覧に出てくるのは、Claude の GitHub アプリを入れたリポジトリだけです。

1. <https://github.com/apps/claude/installations/new> を開く
2. 自分のアカウントを選ぶ（すでに入っているときは **「Configure」**（設定）を押す）
3. **「Only select repositories」**（選択したリポジトリのみ）で、2-1 で作ったコピーを追加する
   - 「All repositories」（すべてのリポジトリ）になっている場合は、そのままで大丈夫です
4. **「Save」**（保存）または **「Install」**（インストール）を押して、claude.ai/code を開き直す

それでも解決しないときは、Claude が出したメッセージをそのままコピーして、このキットの GitHub Issues
<https://github.com/shojikumaru/meet-telop-kit/issues> で相談してください。Issues は誰でも見られるので、
録画のリンクや名前など、見られて困るものは書かないでください。
